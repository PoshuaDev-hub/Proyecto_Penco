# Sistema de Reclutamiento Abreviado - Hospital Penco Lirquen (RRHH)

Monorepo Django + React/Vite para estandarizar el proceso de seleccion psicolaboral.

## Estructura
- `backend/` Django + DRF (apps: seleccion, pautas, preguntas)
- `frontend/` UI responsiva (PC/celular)
- `scripts/preflight-check.js` verificacion automatica
- `deploy/debian/` configuracion Nginx/Gunicorn/systemd

## Comandos
- `npm run dev` desarrollo
- `npm run demo` demo (con seed)
- `npm start` alias de demo

## Git
- `main` produccion
- `demo-day-v1` integracion Demo Day
